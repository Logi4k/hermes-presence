# Project Instructions

This project uses the shared agentic-stack brain in `.agent/`.

Before non-trivial debug, refactor, deploy, migration, timestamp/date, update,
or git work, run:

```bash
python3 .agent/tools/recall.py "<one-line task intent>"
```

Read `.agent/AGENTS.md`, `.agent/memory/personal/PREFERENCES.md`, and
`.agent/memory/semantic/LESSONS.md` when relevant. Log high-signal events with
`.agent/tools/memory_reflect.py`.
